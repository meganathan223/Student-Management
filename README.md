# Student Management 🎓

A simple student management web application built with React and Tailwind CSS. View student details and manage your favorite students.

## Features

- View a list of students.
- Display student profile images and details.
- Add students to favorites.
- Remove students from favorites.
- Navigate between Students and Favorites pages.
- Responsive card layout.
- Interactive buttons and hover effects.

## Technologies Used

- React
- JavaScript
- Vite
- Tailwind CSS
- React Router DOM

Open the local URL shown in your terminal to view the application.
